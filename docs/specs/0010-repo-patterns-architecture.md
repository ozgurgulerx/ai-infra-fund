# 0010 Repo Patterns Architecture

## Purpose

Capture implementation patterns borrowed from research repos without copying incompatible code.

## Patterns To Adopt

- weight-centric output contract from FinRL-style systems
- Qlib-style research workflow separation
- deterministic event objects for runs and backtests
- dry-run operational discipline
- explicit config and persistence
- benchmark and Monte Carlo ergonomics
- connector interfaces for data providers

## License Rule

Study all referenced repos safely. Reuse direct code only when license review permits it. Treat GPL/AGPL/Commons-Clause projects as architecture references unless explicitly approved.
