# 0011 Implementation Roadmap

## Purpose

Define phase order.

## Phases

1. Governance scaffold.
2. Contracts and schemas.
3. PostgreSQL + pgvector data spine.
4. Model router and ModelRun ledger.
5. Deterministic signals and portfolio.
6. Evidence ingestion and provenance.
7. Recommendation artifacts and audit.
8. Evaluation harness.
9. Local read-only UI.

## Rule

Each phase starts with tests and ends with architecture policy tests.
