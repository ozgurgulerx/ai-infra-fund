# 0002 Trading Policy

## Purpose

Define the financial safety boundary.

## Policy

The product is advisory-only. It may produce buy, accumulate, hold, watch, trim, avoid, and exit-candidate recommendations. It must not send orders to a broker, exchange, venue, or trading API.

## Allowed

- local portfolio records
- local trade journal entries
- intended trade notes
- completed manual trade records
- target-weight recommendations
- recommendation-vs-actual comparison
- risk and concentration warnings

## Forbidden

- live order placement
- broker credentials
- order routing
- execution algorithms
- hidden order endpoints
- UI controls that imply real trading execution

## Recommendation Requirements

Every recommendation must include:

- advisory-only label
- evidence IDs
- model run IDs
- signal bundle ID
- target weights ID
- deterministic checks

TargetWeights must be generated by deterministic portfolio code.
