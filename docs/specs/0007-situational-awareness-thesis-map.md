# 0007 Situational Awareness Thesis Map

## Purpose

Define thesis mapping for AI infrastructure research.

## Thesis Map Requirements

- themes
- tickers
- claims
- evidence links
- confidence
- horizon
- contradiction markers
- stale-thesis markers

## Evidence Requirements

Every thesis node must link back to source evidence. Claims without provenance cannot influence recommendations.

## Model Use

LLMs may extract and summarize thesis claims. Deterministic code owns score aggregation and staleness penalties.
