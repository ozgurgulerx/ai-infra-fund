# Product

## Mission

Build a private, local-first, cloud-model-assisted financial analyst system for AI infrastructure, AI ecosystem, and quantum-tech equities. The system should help produce high-alpha research judgment by continuously organizing evidence, computing deterministic signals, evaluating recommendations, and explaining portfolio implications.

Use `docs/ALPHA_ANALYST_PRINCIPLES.md` to keep product work focused on catalyst-driven, evidence-backed, ticker-level AI infrastructure opportunity analysis.

## Product Boundary

This is an advisory-only research and control-room system, not autonomous trading software.

Allowed outputs:

- buy, accumulate, hold, watch, trim, avoid, and exit-candidate recommendations
- target-weight suggestions generated by deterministic portfolio code
- risk, concentration, thesis, technical, sentiment, fundamental, and forward-indicator analysis
- local trade journal entries for intended or completed manual trades
- recommendation-vs-actual comparison and evaluation artifacts

Forbidden outputs or surfaces:

- live order placement
- broker integration or broker credentials
- order routing or execution algorithms
- hidden execution endpoints
- execution-like UI controls
- LLM-owned final scores, constraints, backtests, or target weights

## V1 Product Shape

V1 is a read-heavy analyst cockpit:

- evidence ingestion and provenance
- AI equity watchlist intelligence
- deterministic signal and portfolio analysis
- recommendation artifacts with audit links
- backtests, walk-forward checks, stress tests, and model shadow comparison
- read-only dashboard and local journal

## Model Boundary

LLMs may classify, extract, summarize, review, and explain. Deterministic code owns numeric scores, risk, backtests, constraints, target weights, publication checks, and recommendation suppression.

All model routing must go through `config/model_profiles.yaml`. Every model call must create a `ModelRun` record. Private research is local-only by default; cloud calls must pass data-class policy.
